# checkgraph

Check identifiers and graph tokens for idempotent workflows.

**Site:** https://theworker02.github.io/checkgraph/

## Install / run

```bash
git clone https://github.com/theworker02/checkgraph.git
cd checkgraph
node src/cli.js
node --test
```
